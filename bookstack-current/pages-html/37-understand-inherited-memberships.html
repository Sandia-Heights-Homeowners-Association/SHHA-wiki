Understand inherited memberships

For office staff, membership volunteers and administrators reviewing owners with more than one property. Start in Addresses & people → Advanced → Quick checks → Owners & accounts → Ownership & membership.

SHHA’s shared ownership membership rule

SHHA uses shared ownership for membership coverage. Anyone on a dues-paying property extends membership to other properties they own or co-own. Those additional properties have inherited membership; their complete co-owner lists do not have to be identical. Coverage must come from an actual dues-paying property; it does not pass onward through a co-owner whose connection is only to an inherited property.

Which property pays dues matters

Alice owns A. Alice and Bob co-own B. Bob owns C.

Actual dues-paying propertyCoverageReason
A, owned by AliceA pays; B inherits; C is not covered by A’s payment.Alice’s payment extends to B. Bob’s connection to inherited B does not extend that coverage to C.
B, co-owned by Alice and BobB pays; A and C both inherit.Both Alice and Bob are on the dues-paying property, so coverage extends to the other properties each owns or co-owns.

Why a website members-only export is incomplete

The website does not currently apply shared-ownership coverage. It records each property’s Is Member flag; the ownership comparison views are in Toolbox. A property absent from a members-only export may still be covered through shared ownership.

As of November 18, 2026, SHHA estimates that exporting only website members misses roughly 100 properties under this membership definition. This is an approximate coverage estimate, not an audited count of dues payments. Check shared ownership before classifying an address as uncovered or choosing an outreach audience.

Toolbox comparison definitions

Use Shared ownership as the starting comparison, then check the actual dues-paying source within each group. The tool can group a chain more broadly than SHHA’s coverage rule. It retains Individual properties and Identical ownership as alternative comparisons; no comparison result updates website records or verifies SHS billing.

DefinitionWhat it groupsSeparate comparison example
Individual propertiesEach property is a separate membership unit.Counts X, Y and Z as three separate units.
Identical ownershipProperties group only when their complete lists of linked owners match.Alice owns X and Y. Alice and Bob own Z. X and Y group together; Z stays separate: two units.
Shared ownershipProperties group through a common linked owner, including connected chains of co-owners.The same X, Y and Z group together through Alice: one unit.

The practical difference is often an extra co-owner: “Alice” and “Alice + Bob” are different complete owner lists for Identical ownership, but share Alice for Shared ownership.

The tool’s Shared ownership comparison can join the whole A–B–C chain above. Apply SHHA’s actual coverage rule within that group: C does not inherit when only A pays dues; C does inherit when jointly owned B is the dues-paying property. A connected group alone is not a coverage or billing decision.

Read the two inherited counts carefully

  • Inherited memberships is the selected scenario’s count of properties beyond one per group. It can include groups with no property currently marked Member. It is not a count of newly enrolled or paying members. Apply the dues-paying-source check before treating a grouped property as covered.
  • Possible inherited properties / count identifies properties not marked Member in a group that also contains a property marked Member. These are review candidates; a current Member flag is not billing evidence.

Review a group before outreach or changes

  1. Select Shared ownership to review the chosen membership rule. Read Details for the definition and example; the other definitions remain available for comparison.
  2. Review Owners, All properties & membership, Already marked Member, Possible inherited properties and Possible inherited count.
  3. With Identical ownership or Shared ownership selected, use Only possible inherited memberships to narrow to groups with a recorded Member property and another property not marked Member. Leave it unchecked to see all multi-property groups, including groups whose properties are all marked Member or none are. This checkbox is hidden for Individual properties, which has no inheritance grouping.
  4. Check the actual linked owner accounts and address/unit. Matching names do not establish that two accounts are the same person.
  5. Identify the actual dues-paying property and the person’s connection to it, then check their ownership or co-ownership of each additional property. Do not extend coverage through someone whose only connection is to an inherited property. Resolve uncertain ownership or billing with the office. Use the membership request and review process for a real enrollment request.

Choosing a definition changes the comparison, not dues, property flags, resident links or GRIT delivery. A property whose previous household’s Member flag remains on is a separate record-review issue; it can hide the new resident’s join prompt. See membership requests and tracking.
