# Overview

**Who this is for:** anyone using SHHA IT services, from first-time volunteers to the next IT administrator. Choose your route below. You can read this wiki without signing in; editing uses your approved Microsoft identity.

**Any SHHA volunteer who wants their own SHHA email address may have one.** A personal address such as `first.last@sandiahomeowners.org` is available to volunteers as well as staff. Volunteers may also keep using personal email for committee messages and approved SharePoint guest access. Ask office staff for your preferred option; see [account setup and current license costs](https://wiki.sandiahomeowners.org/books/shha-it-help-guide/page/sop-new-users-mailboxes-groups).

For an email-address request, contact [office staff](mailto:office@sandiahomeowners.org). For setup or access problems, contact [IT Help](mailto:ithelp@sandiahomeowners.org).

<a id="bkmrk--2"></a>## What System Does SHHA Use?

SHHA primarily uses **Microsoft 365** for:

- Committee mailing lists
- Shared inboxes (officer roles)
- File storage (SharePoint)
- Internal collaboration
 
Microsoft 365 owns Board meeting dates; the staff-selected Google calendar owns GRIT deadlines. Toolbox imports dates. Staff save, review and activate reminder setups in Toolbox; importing an event does not authorize sending.

---

<a id="bkmrk--4"></a>## Do I Need a New Microsoft Account?

**If you choose personal-email guest access:** use the same email address that received your SHHA invitation. If you request your own SHHA mailbox, office staff arrange a separate licensed SHHA account.

When first added, you receive a Microsoft invitation email and must accept it once. After acceptance you can:

- Access committee SharePoint files
- Receive group emails
- Open shared documents
 
If access fails, the most common cause is that the original invitation was never accepted.

<a id="bkmrk--6"></a>## Committee Mailing Lists (Microsoft Groups)

Each SHHA committee has a mailing list so one address reaches the whole committee.

### Typical flow

1. Committee chair informs office staff.
2. Office invites volunteer as an external Microsoft user.
3. Volunteer accepts Microsoft invitation.
4. Volunteer is added to committee mailing list.
 
<div id="bkmrk-invitation-emails-ma">Invitation emails may mention Teams or other services. You can ignore those references.</div>---

<a id="bkmrk--8"></a>## Committee SharePoint Sites (Where Files Live)

Each committee has a SharePoint site that acts as its long-term file cabinet and working library.

<div id="bkmrk-important%3A-sharepoin">**Important:** SharePoint navigation through Microsoft menus is often confusing. Use the direct SharePoint links provided in committee materials or this help guide.</div>---

<a id="bkmrk--10"></a>## File Sharing Rule (Most Important)

**Do not** try to share files directly with committee groups when members are external users. Instead:

1. Upload the file to SharePoint.
2. Note the folder and file name in the committee Documents library.
3. Email the committee site address from [Quick Links](/link/3), folder and file name to the committee mailing list.
 
Follow the [SharePoint screenshot guide](/link/7). Do not use Share or Copy link as the handoff for external members; keep the working document in the group library.

---

<a id="bkmrk--12"></a>## Shared Role Inboxes (Officers)

Officer mailboxes stay with the role, not the person. Examples:

- `president@sandiahomeowners.org`
- `vicepresident@sandiahomeowners.org`
- `secretary@sandiahomeowners.org`
- `treasurer@sandiahomeowners.org`
 
**Best practice:** Reply from the shared role inbox, or CC it, so records are preserved for SHHA business.

---

<a id="bkmrk--14"></a>## Board Materials and Calendar

- Board materials should be uploaded directly to Board SharePoint.
- Board reminder setups are reviewed and activated in SHHA Toolbox → Reminders. Edit Board meetings in Outlook or Teams and invite admin@sandiahomeowners.org. GRIT deadlines use the staff-selected Google calendar. Contact office staff or IT Help about missing reminders.
 
If reminders are missing, contact office staff or **ITHelp@sandiahomeowners.org**.

---

<a id="bkmrk--16"></a>## Record-Keeping and Archive

All committee mailing lists include an archival account (`admin@sandiahomeowners.org`) for retention.

The archive inbox is not monitored and does not reply.
